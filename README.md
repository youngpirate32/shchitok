# Щиток

Редактор однофазной квартирной проводки в одном файле `index.html`: ввод, автоматы, советские пробки ПАР, счётчики (электронный и СО-И446), нулевая шина, WAGO, фаза и ноль, двухжильный кабель. Показывает, где есть напряжение, и считает токи.

Открывается со схемой по умолчанию; изменения сохраняются в браузере. Схему можно выгрузить и загрузить кнопкой «Схема в JSON».
